Dataset guide

Download the task-instance definitions and their referenced assets together. Preserve the directory structure so that every task instance can locate its behavioral conditions and reference motions.

RoboSteer on Hugging Face ↗

Download and place the data

  1. Open the RoboSteer dataset on Hugging Face above and follow its download instructions.
  2. Download the repository contents into one local folder. That folder is the dataset root.
  3. Keep Data/ and Tasks/ side by side, with all nested folders intact.
  4. Resolve each asset path against the dataset root, not the directory containing the task JSON.

The outer folder can have any name. A code checkout may live elsewhere; its dataset-root setting must point to this outer folder. A specific evaluator command will be documented with the code release.

RoboSteer contains 38,522 source motions, 77,044 human and rendered motion sequences spanning 91.58 hours, and 773,716 behavioral task instances across three levels of behavioral steerability.

Directory structure

dataset-root/
├── Tasks/
│   ├── Level1/
│   │   ├── full_conditioning_reproduction/
│   │   ├── temporal_completion/
│   │   └── spatial_completion/
│   ├── Level2/
│   │   ├── Amplitude/   BodyRestrain/   Direction/
│   │   ├── Speed/       Trajectory/
│   │   └── Order/       Times/  (local construction)
│   └── Level3/
└── Data/
    ├── Level1/
    ├── Level2/
    ├── Level3/
    └── Shared/
        ├── Motion/
        ├── Video/Human/
        ├── Video/Skeleton/
        └── Metadata/

Tasks/ contains JSON task-instance definitions. Data/ contains media, motion parameters, and task-specific assets. Shared numbered folders group reusable assets; they are not task levels or category labels.

Read a task

FieldMeaning
metadataTask identity, level, family, variant, source asset references, and duration.
input.promptsGeneral and task-specific instructions.
input.modalitiesText and the audio, video, image, or spatial conditions used by Levels 1 and 2.
input.interleave.sequenceThe ordered multimodal input sequence used by Level 3, including segment intervals or image timestamps.
ground_truthReference or target motion paths, plus task-specific information.

For an asset such as Data/Shared/Motion/<shard>/<sample>, the resolved location is <dataset-root>/Data/Shared/Motion/<shard>/<sample>. A value of "none" in rendered_video indicates an absent optional rendering, not a filename.

Motion packages

G1 reference motion folders contain six synchronized CSV files: joint_pos.csv, joint_vel.csv, body_pos.csv, body_quat.csv, body_lin_vel.csv, and body_ang_vel.csv. The accompanying metadata describes conversion and timing. The appendix specifies 50 Hz output and 29 joint degrees of freedom.

Use the per-sample metadata for frame counts, holds, and coordinate conventions. Do not assume that the task's source-video duration equals the stored motion frame count divided by 50.

Order and Times

These two Level 2 constraint types use BABEL-linked AMASS segments. Obtain the source datasets directly from AMASS and BABEL under their respective terms, then construct the task assets locally. The reproducible public construction package is being prepared. These assets are not part of the direct-download preview.

Interpret reference motions correctly

For Amplitude, Speed, Direction, and Body Restrain, the reference motion is the unmodified base action. The instruction describes the behavioral constraint on the generated behavior. Temporal Completion task instances use their specified target interval, and Level 3 preserves the supplied ordering of conditions.

Paper and citation

Benchmarking Behavioral Steerability in Behavior Foundation Models. Author information, the paper link, and BibTeX will be added with the manuscript release.
